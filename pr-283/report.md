## 人が確認すべき点

1. #287 の優先度
   - この PR をマージすると、所属が 1 チームだけのスタッフが退出したときに `users/{uid}.teamIds` が空になる状態（#287）へ到達できるようになる。一次の確認では、その状態で新ソロチームに対する `leaveSpecificTeam` が 404 になった。`leaveTeam` の場合は `teamIds` に退出したチームが残る

2. Emulator を通すテストを必須とするかの最終判断
   - Issue #236 の対応案は「callable を Emulator で通す回帰テストを足す」だが、この PR が追加したのは、書き込み後の読み取りで例外を投げる偽のトランザクションを使うユニットテスト。Emulator は使わない
