# file-issue

## いつ起票するか

- `--kind task`: 今の作業範囲外の既存バグ・技術的負債・仕様の矛盾・テスト不足を見つけたとき。範囲外は直さずに起票する
- `--kind finding`: レビューで出た指摘のうち、他の PR でも起こりうる種類のもの（review-auditor の記録モード）

## 手順

1. 本文を一時ファイルに書く（下記テンプレート）
2. `node scripts/agent/file-issue.mjs --kind task|finding --title "<タイトル>" --body-file <本文>`
   同じタイトルの open Issue があればコメント追記になる。finding はタイトルを「指摘の種類」で付け、同じ種類は同じタイトルにする
3. 出力された URL を返却・PR コメントの「起票した Issue」に書く

## 本文テンプレート

```
## 現象
## 再現手順 / 該当箇所（ファイル:行）
## 影響
## 想定される対応（分かる範囲で）
```
