# 起動指示テンプレート

変更仕様は要約せず、該当ファイルのパスと本文を渡す。

## 実装モード（implementer）

- モード: 実装
- 作業ブランチ:
- 変更単位名:
- 変更仕様: `docs/変更仕様/<変更名>.md`（本文を貼る）
- 担当する受入条件 ID: AC-x, AC-y
- 影響ファイル（想定）:
- 先行単位の成果（あれば）: 完了済み単位が作った型・関数のパス
- 返却形式: regression-check の reference/report-format.md「実装結果」

## 修正モード（implementer）

- モード: 修正
- 作業ブランチ / PR 番号:
- 変更仕様: 同上
- 指摘: レビューコメント全文、または CI 失敗ログ全文
- 返却形式: 同上（指摘への対応を含む）
