# 報告フォーマット

## 回帰確認結果

| コマンド               | 結果                        | 備考                          |
| ---------------------- | --------------------------- | ----------------------------- |
| pnpm verify            | OK / NG                     | NG なら失敗したステップと件数 |
| pnpm test:e2e:smoke    | OK / NG / 対象外            | UI 変更時のみ                 |
| pnpm test:e2e:emulator | OK / NG / 対象外 / 実行不可 | 実行不可なら理由              |

失敗がある場合は下記に該当出力を貼る（ファイル:行 を含める）。

```
（失敗出力）
```

## 実装結果（implementer が返す形式）

- **対象**: 変更単位名または指示内容
- **変更ファイル**: パスと変更概要を1行ずつ
- **追加・更新テスト**: パスとケース名
- **動作確認**: run-and-debug で行った操作と結果（スクリーンショットのパス）
- **回帰確認結果**: 上の表
- **指摘への対応**（修正モードのみ）: 指摘ID / 対応（修正・不修正）/ 理由
- **未確定事項**: 呼び出し元の判断が必要な点。無ければ「なし」
- **起票した Issue**: AGENTS.md「報告書式」
