# production（タスク管理 v2 / 1枚紙）

制作進行（タスク管理 v2）カテゴリの詳細仕様です。機能識別 ID は `PD`。

このディレクトリを、ブリーフ（動画1本の1枚紙）・工程・進め方（プレイブック）・差分の作成・進行・表示に関する唯一の詳細仕様として扱います。

背景・経緯は変更仕様 [production-v2-ai-discord.md](../../変更仕様/production-v2-ai-discord.md) を参照してください。

## 対象範囲

- ブリーフ（動画・配信 1 本を親にした 1枚紙）の作成・見出し編集・状態
- 工程（担当・締切・状態・工程固有の入力項目・やり取り）
- 進め方（チーム固有の工程の型）と、進め方からの工程生成
- 公開予定日からの締切逆算と、公開日変更時の再計算
- 工程の状態遷移（先行工程の完了による自動着手可能化）
- 入力待ち・締切超過・担当未定の検出と表示
- 差分（変更の記録）
- 操作層（Web・Discord・AI・公開 API が共有する操作の定義）

## 対象外

- 既存カンバン（task カテゴリ）。v2 は追加であり置換ではなく、相互移行も行わない
- Discord へのスレッド投稿・ボタン・ダイジェスト（integration カテゴリ）
- 進め方の対話による引き出し、運用からの学習提案（ai カテゴリ）
- 公開 API・MCP サーバー（api カテゴリ。新設予定）

## 他カテゴリとの境界

### task との境界

- v2 の工程は `teams/{teamId}/tasks` と別コレクションで、列（`TaskStatus`）やカテゴリを使わない
- 単発の作業（機材購入など）は従来のタスクとして扱い、ブリーフに無理に入れない

### team との境界

- 担当者・出演者はメンバー UID を参照する。ロール定義と権限境界は team を参照する
- Discord メンション用のユーザー名（`TeamMember.discordUsername`）は team が保持する

### integration との境界

- ブリーフは Discord スレッドへの参照（`discord`）を持つが、スレッドの作成・要約更新・ボタン処理は integration を参照する

### ai との境界

- 進め方の `origin: dialogue` は ai カテゴリの対話機能が作る。本カテゴリは構造だけを定義する
