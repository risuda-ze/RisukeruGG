# 創業計画書（リスケるGG）

## 1. 創業の動機

ゲーム実況グループでの活動や配信経験を通して、チーム内でのスケジュールの共有漏れ、DMや口頭で行われるコラボ日程調整の煩雑さ、そして動画編集・サムネイル作成などの制作タスクの管理不足などの、配信業に関係のない課題を痛感してきました。
既存の汎用カレンダーツールやタスク管理では配信特有の情報（同時配信先、コラボ相手、アーカイブURL等）を一元管理できず、配信者が本業である「配信」に集中できる環境を提供したいと考え、配信者特化型チームスケジュールアプリ『リスケるGG』の開発・事業化を計画しました。

## 2. 経営者の略歴等

- 略歴:会社員として勤務する傍ら、個人開発者としてWindows向け業務アプリケーションやWebベースのツール開発に行う。また、自身もグループ系のゲーム実況者として活動しており、ターゲットユーザーのニーズや業界に慣れ親しんでいる
- 取得資格等:基本情報技術者試験合格

## 3. 取扱商品・サービス

- 商品・サービス名:配信者特化型チームスケジュール管理アプリ『リスケるGG』
- 内容:
  - チーム全員がリアルタイムで共有できるスケジュール・配信枠管理機能
  - コラボの日程調整から確定までをアプリ内で完結させる調整機能
  - 撮影・編集・サムネイル作成などの制作タスクを可視化するカンバンボード機能
  - （将来拡張）YouTube/Twitch API連携による配信自動取得機能
- セールスポイント（強み）:
  汎用ツールにはない「配信者・Vtuber」に完全に特化したUI/UX設計。開発者自身が当事者であるため、ユーザーの痒い所に手が届く機能選定（日程調整とタスク管理の統合）が行われている点。

  汎用的なカレンダーやタスク管理ツールでは対応しきれない、「配信者・Vtuber特有の業務フロー」に特化している点が最大の強みです。具体的には、配信枠の管理、コラボ相手との日程調整、同時配信先の整理、配信告知、サムネイル制作、動画編集、アーカイブ管理といった一連の作業を一つのサービス上でまとめて管理できます。これにより、配信者が複数のツールやDMを行き来する負担を減らし、本来注力すべき配信活動や企画準備に集中できる環境を提供できます。また、開発者自身が配信活動の当事者であるため、現場感覚に基づいた機能改善を継続できる点も、他の汎用ツールにはない競争優位性です。

## 4. 取引先・取引関係等

- **販売ターゲット:**
  - プライマリ: ゲーム配信者（Twitch / YouTube）、登録者数0〜10万人規模の個人〜小規模チーム
  - セカンダリ: Vtuber、およびその制作チーム（編集者・マネージャー等）
- **提供方法:** Webブラウザ（PWA対応）、Google Playストア経由でのアプリ配信。
- **集客・販促:** 配信者コミュニティ内での口コミ、SNS（X等）での告知。
