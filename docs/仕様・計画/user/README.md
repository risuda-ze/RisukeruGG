# user

認証・アカウント管理カテゴリの詳細仕様です。

このディレクトリを、認証方式・アカウント初期化・セッション維持・アカウント削除時の保持方針に関する唯一の詳細仕様として扱います。

## 対象範囲

- Google OAuth2 を利用した認証方式
- 初回ログイン時のアカウント初期化
- 保護ページへのアクセス制御
- 認証セッションの維持
- アカウント削除後のゴースト保持

## 対象外

- 初回ログイン時に生成されるチームとロール（`member` / `staff`）の詳細
- チーム所属、権限、退出ルール

## 他カテゴリとの境界

### team との境界

- user は認証済みアカウントの生成と保持を扱い、初回所属・ロール・所属切り替えは team を参照する

### notification / platform との境界

- user はアカウント本体の保持を扱い、通知サブリソース運用や端末連携情報の詳細は notification / platform を参照する

## 読む順番

1. この README: user カテゴリの責務と隣接カテゴリの切れ目を把握する
2. [requirements.md](./requirements.md): 認証・アカウント管理の規範要件を確認する
3. [model.md](./model.md): User アカウントの状態と保持フィールドを確認する
4. [flows.md](./flows.md): 初回ログイン、継続利用、削除時の流れを確認する

## 採用する後続仕様

- 認証と初回ログインは 001 の最終記述を採用する
- アカウント削除後のユーザー情報保持は 007 の後続仕様を採用する
- 旧仕様と後続仕様が衝突する場合は後続仕様を優先する
