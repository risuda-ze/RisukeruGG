# team

チーム管理カテゴリの詳細仕様です。

このディレクトリを、チーム作成・参加・ロール管理・退出・複数チーム所属・アクティブチーム切り替えに関する唯一の詳細仕様として扱います。

## 対象範囲

- チーム作成
- チームコード参加
- ロール管理
- 所属と退出
- アクティブチーム切り替え

## 対象外

- Google ログイン自体の認証方式とセッション維持
- プラン制限値やアップグレード条件
- メンバー削除やロール変更に伴う通知配送の詳細

## 他カテゴリとの境界

### user との境界

- team は所属とロールを扱うが、ログイン方式や認証セッション本体は user を参照する
- team は `currentTeamId` や `teamIds` を利用する場合があるが、その保持主体は user を参照する

### plan との境界

- team は参加時にプラン判定結果を利用するが、人数制限の基準値や課金状態は plan を参照する

### notification との境界

- team は通知対象イベントを持つが、配送実装や既読管理は notification を参照する

## 読む順番

1. この README: team カテゴリの責務と境界を把握する
2. [requirements.md](./requirements.md): チーム管理の規範要件を確認する
3. [model.md](./model.md): チーム・メンバー・ロール関連の保持項目を確認する
4. [flows.md](./flows.md): チーム作成、参加、退出、ロール変更、切り替えの流れを確認する
