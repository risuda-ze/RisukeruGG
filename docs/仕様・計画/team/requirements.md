# team requirements

## チーム管理

- **TE-001**: 認証済みユーザーはチームを作成でき、自動的にオペレーターロールが付与される
- **TE-002**: チームには固有のチームコードが自動生成。オペレーターはいつでもリセット可能。旧コードは即時無効化
- **TE-003**: ユーザーは設定画面でチームコードを入力してチームに参加。プラン制限を超える場合は参加をブロック
- **TE-004**: チームコードで参加したユーザーには ROM専ロールが付与。オペレーターがその後ロールを変更可能
- **TE-005**: 3 つのロール: オペレーター（全権限）、メンバー（スケジュール・タスクの作成・編集）、ROM専（閲覧のみ）。チーム内に複数のオペレーターが共存可能
- **TE-006**: オペレーターはメンバーのロールをオペレーター・メンバー・ROM専 の間で変更可能。ただし変更後もチームにオペレーターが 1 人以上いることが必要
- **TE-007**: オペレーターはメンバーをチームから Kick 可能（オペレーター自身を除く）
- **TE-008**: チームから削除されたメンバーはチームのデータに一切アクセス不可
- **TE-009**: メンバー削除時、未完タスクは「未アサイン」に移行しオペレーターに通知。完了済みタスク・過去スケジュールは保持（作成者名は「元メンバー」表示）
- **TE-010**: 1 ユーザーが複数チームに同時所属できる
- **TE-010-1**: 初回 Google ログイン時、ユーザーは自動的にソロチームのオペレーターとして登録
- **TE-010-2**: ユーザーはいつでも特定チームから退出可能。ロールとチーム状態により挙動が異なる:
  - **メンバー・ROM専**: 制限なく退出できる
  - **オペレーターで、メンバーが自分のみ（ソロチーム）**: チームを自動削除して退出できる（**spec 008 追加**）
  - **オペレーターで、自分以外にオペレーターが存在する場合**: そのまま退出できる
  - **オペレーターで、自分が唯一のオペレーターかつメンバーが 2 人以上の場合**: 別メンバーをオペレーターに昇格させてから退出
- **TE-011**: チームスイッチャーで任意のチームをアクティブチームに切り替え可能（spec 003 追加）
- **TE-012**: メンバーは Discord のユーザー名（`discordUsername`）をチームごとに任意で登録できる。登録は本人（`/settings/profile`）またはオペレーター（`/team` のメンバー行）が行い、Firestore ルール上は既存のメンバー更新権限（本人またはオペレーター）で制御する。ログイン連携（OAuth）は行わない
  - **TE-012-1**: 保存前に先頭の `@`・前後空白を除去し小文字化する。形式は 2〜32 文字、英小文字・数字・`_`・`.` のみ、`.` の連続不可。空で保存した場合は未設定（null）に戻す
  - **TE-012-2**: ユーザー名を変更・解除した場合は解決済み ID のキャッシュ（`discordUserId`）を null に戻す。ID の解決と保存は Discord 連携側（integration IN-015）が行う
  - **TE-012-3**: 取得するのはユーザー名と解決した ID のみで、Discord の認証情報やメッセージ本文は保持しない。値は同一チームのメンバーのみ閲覧でき、アカウント削除時にメンバー情報とともに消える
