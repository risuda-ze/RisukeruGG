# collab

コラボ日程調整カテゴリの詳細仕様です。

このディレクトリを、コラボセッション作成・公開回答フォーム・日程確定・再調整・複製・コラボ調整画面 UI に関する唯一の詳細仕様として扱います。

## 対象範囲

- コラボセッションの作成と共有 URL 発行
- 公開回答フォームでの無認証回答
- 日程確定、キャンセル、期限切れ処理
- 確定済みコラボの再調整とコピー新規作成
- コラボ調整画面と公開フォームの UI 改善

## 対象外

- LIGHT / PARTY プランの月次上限値とアップグレード導線
- 確定時に生成されるスケジュールの詳細項目や Google カレンダー同期
- 通知カテゴリ定義、既読管理、プッシュ通知設定
- Google ログイン自体の認証方式とセッション維持
- コラボ以外の共通ナビゲーション仕様

## 他カテゴリとの境界

### plan との境界

- collab はコラボ調整の作成可否を扱うが、月 3 件制限やアップグレード条件そのものは plan を参照する

### schedule との境界

- collab は確定結果として `linkedScheduleId` を扱うが、作成される `ScheduleEntry` の項目や保持・削除ルールは schedule を参照する

### notification との境界

- collab は通知を発生させるイベントだけを持ち、配送方法・既読・受信設定は notification を参照する

### user / team との境界

- collab は認証済み利用者とアクティブチームを前提に動作し、その判定と保持は user / team を参照する
- collab は操作可能ロールを利用するが、`operator` / `member` の定義自体は team を参照する
