# collab flows

## コラボセッション作成フロー

1. メンバーがコラボ調整画面から新規作成を開始する
2. タイトル・コラボ相手名・候補日程（1〜5 件）・有効期限（1〜30 日）を入力する
3. plan カテゴリの月次上限チェックを行う
4. 候補日程を ISO 8601 UTC 文字列へ正規化して `createCollabSession` に渡す
5. `teams/{teamId}/collabSessions/{sessionId}` を `open` 状態で作成する
6. 公開回答ページ用の共有 URL を生成し、Discord 等で手動共有する

## 公開回答フロー

1. 外部相手が共有 URL にアクセスする
2. セッションが `open` であり、有効期限内であることを確認する
3. Step1 で回答者名を入力する
4. Step2 で候補日程ごとに OK / NG / 未定を回答し、必要なら代替日程を入力する
5. 代替日程を ISO 8601 UTC 文字列へ正規化して送信する
6. Step3 で必要に応じてコメントを入力して送信する
7. `respondToCollab` が回答内容を `participantResponses` に保存し、コメントがあれば回答コメントとして `comments` に追記する
8. 回答受信の Discord 通知を送る（integration の IN-003 / IN-004）

## 日程確定フロー

1. 打診側がコラボ詳細画面で回答状況と回答コメントを確認する
2. 確定する候補日時を選択して確定を実行する
3. コラボセッションの状態を `confirmed` に変更し、`confirmedDate` を設定する
4. 打診側チーム配下にコラボ用 `ScheduleEntry` を自動作成し、その ID を `linkedScheduleId` に保存する
5. 共有 URL を即時無効化し、以後の公開回答受付を停止する

## キャンセルフロー

1. 打診側がコラボ詳細画面からキャンセルを実行する
2. セッション状態を `cancelled` に変更する
3. 共有 URL を無効化する
4. すでに `confirmed` で `linkedScheduleId` がある場合は紐づくスケジュールを削除する

## 期限切れフロー

1. セッションが `open` のまま `expiresAt` を過ぎる
2. 共有 URL へのアクセスでは「期限切れ」状態を表示する
3. バックエンドは対象セッションを `expired` として扱う

## 再調整フロー

1. `confirmed` セッションの詳細画面で「再調整する」を押す
2. 確認ダイアログで承認する
3. `reopenCollabSession` を実行し、状態を `open` に戻す
4. `confirmedDate` と `linkedScheduleId` をクリアし、紐づくスケジュールを削除する
5. 候補日程・参加者・タイトル・内容・回答コメントを保持したまま再回答を受け付ける

## コピーして新規作成フロー

1. `confirmed` セッションの詳細画面で「コピーして新規作成」を押す
2. 新規作成フォームを、タイトル・パートナー名・有効期限を引き継いだ状態で開く
3. 新しい候補日程を入力して新規セッションを作成する
4. 元のセッションのステータスや回答履歴は変更しない

## コラボ調整画面表示フロー

1. コラボ調整画面を開く
2. open セッションを「受信・送信したコラボ調整」セクションに表示する
3. confirmed セッションを「予定確定したコラボ」セクションに表示する
4. 見出し横に受信 / 送信件数を表示し、TopBar には件数を再掲しない
5. 公開回答フォームはモバイルでは縦積み、PC では 3 カラムで表示する
