# ui

UI・ナビゲーションカテゴリの詳細仕様です。

このディレクトリを、サイドバー・TopBar・共通ナビゲーション状態に関する唯一の詳細仕様として扱います。

## 対象範囲

- サイドバーの開閉、セクション展開、アクティブ判定、ロゴ遷移
- `SidebarState` を中心とした共通 UI 状態
- テーマ（ダーク / ライト）の切り替えと選択の保持

## 対象外

- task / schedule / collab / team / plan 各カテゴリの業務ルールや表示内容の正本
- user カテゴリの認証方式、アカウント初期化、セッション維持
- platform カテゴリの PWA 配布、Service Worker、オフライン制御

## 他カテゴリとの境界

### task / schedule / collab / team / plan との境界

- ui は各カテゴリのデータを表示する導線と共通状態だけを扱い、業務ルールや制約は各カテゴリを参照する
- 画面内でどの値を表示するかは ui が扱うが、値そのものの定義や更新条件は各カテゴリの正本に従う

### user / platform との境界

- ui は認証状態やオフライン状態を見た目に反映するが、その状態の正本は user / platform を参照する

## 読む順番

1. この README: ui カテゴリの責務と隣接カテゴリの境界を把握する
2. [requirements.md](./requirements.md): サイドバー・TopBar の規範要件を確認する
3. [model.md](./model.md): `SidebarState`、ナビゲーション定義などの派生 UI 状態を確認する
4. [flows.md](./flows.md): サイドバー操作、テーマ切り替えの流れを確認する

## 採用する後続仕様

- サイドバーの基本要件は spec 002 の最終記述を採用する
- サイドバーのアクティブ判定は spec 008 の後続仕様を採用し、最長一致で 1 項目のみをアクティブにする
- 旧記述と後続仕様が衝突する場合は後続仕様を優先する
