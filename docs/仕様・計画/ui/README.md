# ui

UI・ナビゲーションカテゴリの詳細仕様です。

このディレクトリを、サイドバー・TopBar・通知ドロップダウン・設定/通知画面の表示導線・共通ナビゲーション状態に関する唯一の詳細仕様として扱います。

## 対象範囲

- サイドバーの開閉、セクション展開、アクティブ判定、ロゴ遷移
- TopBar の通知ベルと通知ドロップダウン
- 設定/通知画面の通知一覧と削除導線
- `SidebarState` を中心とした共通 UI 状態

## 対象外

- task / schedule / collab / team / plan 各カテゴリの業務ルールや表示内容の正本
- notification カテゴリの通知種別、配送先、既読管理
- user カテゴリの認証方式、アカウント初期化、セッション維持
- platform カテゴリの PWA 配布、Service Worker、オフライン制御

## 他カテゴリとの境界

### task / schedule / collab / team / plan との境界

- ui は各カテゴリのデータを表示する導線と共通状態だけを扱い、業務ルールや制約は各カテゴリを参照する
- 画面内でどの値を表示するかは ui が扱うが、値そのものの定義や更新条件は各カテゴリの正本に従う

### notification との境界

- ui は通知ベル、未読バッジ、通知ドロップダウン、設定/通知画面の通知一覧と削除導線を扱う
- 通知エンティティの型、通知カテゴリ、既読状態、配送条件は notification を参照する

### user / platform との境界

- ui は認証状態やオフライン状態を見た目に反映するが、その状態の正本は user / platform を参照する
