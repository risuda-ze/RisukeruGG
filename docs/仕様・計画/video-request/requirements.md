# 動画依頼の要件

## VR-001 依頼作成・編集

| 項目                               | 動作                                                                                                                                                             |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| タイトル・動画の種類・編集内容     | タイトルをスレッド名に使う。画面で横動画かショートを選ぶ。タイトルと編集内容は空白のみでは保存できない。                                                         |
| 担当編集者                         | DiscordユーザーID（17〜20桁の半角数字）を1名以上入力する。複数人はカンマ区切り。重複は1名にまとめる。編集者はリスケるGGへの登録不要。                            |
| プロマネのリンク・タイトル案（仮） | どちらも必須。プロマネはHTTPまたはHTTPSのURL。仮タイトルをサムネの制作依頼に掲載する。                                                                           |
| 共有事項・編集開始日               | 任意。共有事項は編集スレッドに掲載する。                                                                                                                         |
| 初稿納期・完パケ納期               | どちらの動画形式でも必須。編集開始日 ≦ 初稿納期 ≦ 完パケ納期。同日は可。順序違反は作成・編集とも保存できない。両タスクの期限とサムネの納期には完パケ納期を使う。 |

## VR-002 チーム別のタスク連携

管理権限のある所属者がカテゴリ設定で送信待ち・制作中・納品確認待ちに対応する3列を選ぶ。列は相互に異なり、完了列を兼ねない。設定が不足した場合は作成を中止する。タスク名や列の表示名は判定条件にしない。承認時はチームの完了列に移動する。

## VR-003 サムネイル制作

「サムネ制作も依頼する」を有効にしたチームでのみ、動画依頼と同時にサムネタスクと専用スレッドを作る。設定変更は新規依頼から適用する。制作中・確認待ちにサムネだけを承認できる。

## VR-004 操作権限と通知

チームの `operator` と `member` が作成・編集・修正・承認できる。列設定とオーナー用資料登録は管理権限が必要。編集者はチームに登録せずDiscordユーザーIDで指定できる。納品URLと画像投稿リンクを依頼カードから確認でき、修正と承認は対象のスレッドへ通知する。
