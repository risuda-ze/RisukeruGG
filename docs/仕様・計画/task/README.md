# task

制作タスク管理カテゴリの詳細仕様です。

このディレクトリを、カンバンタスクの作成・編集・表示、列とカテゴリ管理、担当者・期限・進捗集計に関する唯一の詳細仕様として扱います。

## 対象範囲

- カンバンタスク管理
- 既存タスクを参照した複製新規作成
- 列とカテゴリ管理
- 担当者と期限
- タスク詳細編集
- 進捗集計
- タスクボードの表示と並び順
- 完了列設定と CSV エクスポート

## 対象外

- チームロールの定義、所属管理、アクティブチーム切り替え
- 動画投稿予定スケジュール自体の管理
- 認証方式やログインセッション管理

## 他カテゴリとの境界

### team との境界

- task は担当者参照と操作可否に team のロールを利用するが、ロール定義や所属管理は team を参照する

### schedule との境界

- task は `linkedScheduleId` による関連付けだけを扱い、スケジュール本体の項目や同期詳細は schedule を参照する

### integration との境界（通知）

- task は通知対象イベント（作成・主要フィールドの変更）を持ち、Discord への配送と通知設定は integration を参照する

### user / plan との境界

- task は認証済み利用者とプラン制限を前提に動作し、その判定と制限値は user / plan を参照する

## 読む順番

1. この README: このカテゴリで決める範囲と隣接カテゴリとの境界を把握する
2. [requirements.md](./requirements.md): タスク管理の規範要件を確認する
3. [model.md](./model.md): Task / TaskStatus / Category（タスク・スケジュール共通）の保持項目と制約を確認する
4. [flows.md](./flows.md): 作成、複製新規作成、詳細編集、列移動、カテゴリ管理、集計反映の流れを確認する

## 採用する後続仕様

- タスク基本要件は 001 の最終記述を採用する
- 詳細モーダル、カテゴリ管理、完了列設定は 002 の後続仕様を採用する
- 並び順や表示修正は 004-s の後続仕様を採用する
- 旧仕様と後続仕様が衝突する場合は後続仕様を優先する
