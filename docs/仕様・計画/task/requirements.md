# task requirements

## 権限

- ロールは「メンバー」（保存値 `member`）と「スタッフ」（保存値 `staff`）の 2 つ。定義と権限の表は [team/model.md](../team/model.md) を参照する
- **TA-001**: Kanban タスクの作成・編集・削除はメンバーのみ可能とする
- **TA-002**: スタッフは Kanban タスクを閲覧のみとする

## タスクデータ

- **TA-003**: タスクの項目は、タイトル（必須）・担当者（任意）・締切日（任意）・カテゴリ（`categoryId` による Firestore 参照）・所属カラム（必須）・説明（`description: string | null`）を持つ
- **TA-004**: `TaskStatus` はタスクのステータス定義として扱い、タスクの状態は `columnId` で一意に表現する。独立した status フィールドは持たない
- **TA-005**: タスクは動画投稿予定スケジュールエントリと任意で紐付け可能とする
- **TA-006**: タスクの作成時と、主要フィールド（担当を含む）の変更時に、チームの Discord 通知チャンネルへ通知する（integration の IN-003-1 / IN-003-2）。担当者は表示名で載せ、個人宛てには送らない

## カラムとボード

- **TA-007**: カンバンのカラムはメンバーが設定画面からカラム名・順序・色を追加・リネーム・削除・並び替え可能とする
- **TA-008**: デフォルトカラムは「TODO / 進行中 / 完了」の 3 つとし、最低 1 つ・最大 10 個まで管理可能とする
- **TA-009**: `TaskStatus` は `role: 'done' | null` フィールドを持つ。`'done'` のとき完了カラム、`null` のとき通常カラムとして扱い、設定画面から 0 個以上のカラムを完了列として設定できる
- **TA-010**: 各 `TaskStatus` は表示用アイコン（`icon`）を設定可能とし、ステータス表示ではラベルとアイコンを常に併記する
- **TA-011**: タスクボードは設定されたカラムを左から順に表示する
- **TA-012**: 各カラム内のタスクは締切が近い順に上から表示する。カテゴリで絞り込んだ場合も同様とし、締切日未設定のタスクは末尾に配置する
- **TA-013**: PC ブラウザではタスクカードをドラッグ&ドロップでカラム間移動可能とする
- **TA-014**: モバイルではタスクカードのボタン操作でカラム変更可能とする
- **TA-015**: タスクボードの表示はレスポンシブとし、デスクトップではカラムを横並びで表示して列幅は均等配分を基本とする。モバイルではカラムを縦並びで表示し、各列は画面幅いっぱいに表示することを基本とする

## タスク詳細と編集

- **TA-016**: タスクカードの編集/削除ボタン以外の領域をクリックすると `TaskDetailModal` が開く
- **TA-017**: `TaskDetailModal` ではステータス・カテゴリ・担当者・期限・タスク説明のインライン編集が可能とする。編集内容はモーダル内のローカル状態にのみ反映し、フッターの保存ボタン押下時に変更されたフィールドのみを一括で Firestore へ保存する（即時保存は行わない）。保存時は楽観的ロック（`updatedAt` 比較）を用い、競合時は保存せずエラーを表示する
- **TA-018**: `TaskDetailModal` の締切日入力は `DateInput` コンポーネント（`DateTimeInput` と同スタイル・`type="date"`）を使用する
- **TA-029**: タスクはコメント機能を持たない。`TaskDetailModal` にコメントの一覧・入力欄を置かない。残しておく内容はタスク説明に書き、やり取りは Discord で行う

## タスク複製新規作成

- **TA-025**: メンバーは `TaskDetailModal` から既存タスクを参照して複製し、新規タスク作成を開始できる
- **TA-026**: 複製開始時は `title`、`columnId`、`categoryId`、`assigneeId`、`dueDate`、`description`、`linkedScheduleId` を新規作成フォームの初期値として引き継ぐ
- **TA-027**: 複製保存時は新しい `taskId` を発行し、`createdBy`、`createdAt`、`updatedAt` は新規タスクとして再生成する。参照元 ID を保持する恒久的なフィールドは追加しない
- **TA-028**: 複製後の通知とスケジュール関連付けは、通常のタスク新規作成と同じルールを適用する

## カテゴリ管理

- **TA-019**: カテゴリは `teams/{teamId}/categories/{categoryId}` コレクションで**タスクとスケジュール共通**として管理し、メンバーのみが追加・編集・削除可能とする
- **TA-020**: 各 `Category` は表示用アイコン（`icon: string | null`）を任意で設定可能とし、設定した場合はタスクカード・詳細モーダル・カテゴリ選択 UI・スケジュールカレンダーで同一アイコンを表示する
- **TA-021**: カテゴリ削除時は関連する全タスクおよび全スケジュールの `categoryId` を `null` に更新する

## 設定・集計・エクスポート

- **TA-022**: `/settings/categories`（カテゴリ設定画面）に「カテゴリの管理」「列の管理」の 2 セクションを表示する。カテゴリはタスク・スケジュール共通のため、この画面がカテゴリ設定の唯一の入口となる
- **TA-023**: メンバーはタスクボードのデータを CSV エクスポート可能とし、全タスクの全項目を含む
- **TA-024**: ダッシュボードのタスク完了率は `column.role === 'done'` のカラム群を完了カラムとして特定して計算する。完了カラムが 0 件のとき完了率は 0% とし、カラム名依存の実装は行わない
