# ai

AIチャットカテゴリの詳細仕様です。

このディレクトリを、AIアシスタント（「AIに相談」）の対話画面・提案生成・登録連携・コンテキスト構築に関する唯一の詳細仕様として扱います。

## 対象範囲

- `/chat` の全画面チャット UI
- AI API ルート（`/api/ai/chat`）とストリーミング応答
- システムプロンプト（対応範囲の制限・提案フォーマット）
- `%%PROPOSAL%%` 提案ブロックの解析と提案カード表示
- 提案からのスケジュール・タスク・コラボ登録
- チャット履歴のセッション内保持

## 対象外

- Discord ボット経由の AI 会話（integration カテゴリを参照。ただしシステムプロンプト・提案解析ロジックは本カテゴリのユーティリティを共用する）
- 登録されるスケジュール・タスク・コラボ自体のデータ定義（schedule / task / collab を参照）
- メンバーの予定（メンバーカレンダー）のデータ定義（schedule を参照）

## 他カテゴリとの境界

### schedule / task / collab との境界

- ai は自然言語から登録内容の提案を生成するが、登録実行は各カテゴリの既存リポジトリ関数を経由する。エンティティの定義・制約は各カテゴリを参照する

### integration との境界

- Discord の `/risukerugg` ボットは ai カテゴリの共通ユーティリティ（システムプロンプト生成・提案解析）を再利用する。Discord 固有のセッション管理・配送は integration を参照する

### team / plan との境界

- ai はアクティブチームのデータをコンテキストとして参照するが、チーム所属・ロール・プラン制限の定義は team / plan を参照する
