# ai flows

## 会話フロー

1. ユーザーがナビゲーションの「AIに相談」から `/chat` を開く
2. メッセージ 0 件の場合は中央配置の入力欄と例示チップを表示する
3. ユーザーがメッセージを送信すると、クライアントはアクティブチームのストアからコンテキスト（タスク・スケジュール・コラボ・メンバー・タスク列・メンバーの予定）を組み立て、会話履歴とともに `POST /api/ai/chat` へ送信する
4. API はシステムプロンプト（今日の日付・チームデータ入り）を生成し、Claude haiku のストリーミング応答を返す
5. クライアントは応答チャンクを逐次アシスタントメッセージへ追記して表示する
6. 会話開始後は入力欄を下部固定に切り替える

## 提案・登録フロー

1. AI 応答に `%%PROPOSAL%%` ブロックが含まれる場合、クライアントは JSON を解析して提案カード（タイトル・日時・担当等の詳細）を表示する
2. ユーザーが「登録する」ボタンを押す、または肯定応答テキスト（「OK」「はい」等）を送信すると登録を実行する
3. 登録は提案タイプに応じて `createSchedule` / `createTask` / `createCollabSession` を呼び出す。人名は `displayName` から UID へ、列名は列 ID へ解決する
4. 複数提案がある場合はすべてを登録する
5. 成功時は提案カードを完了状態にし、失敗時はエラー状態を表示する

## リセットフロー

1. ユーザーが「会話をリセット」操作を行う
2. 会話履歴・提案状態・ローディング状態をすべて初期化する

## 範囲外質問の拒否フロー

1. ユーザーがアプリと無関係な話題（雑談・一般質問等）を送信する
2. AI はシステムプロンプトの対応範囲ルールに従い、定型の断りメッセージのみを返す
