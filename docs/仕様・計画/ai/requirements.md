# ai requirements

## 画面と導線

- **AI-001**: 認証済みユーザーは `/chat`（保護ルート）で AI アシスタントと全画面チャット形式で対話できる
- **AI-002**: ナビゲーション（サイドバー・モバイルツールバー）に「AIに相談」導線を設け、`/chat` へ遷移できる
- **AI-003**: 入力欄はメッセージ 0 件のとき画面中央に配置し（例示チップ付き）、会話開始後は下部固定に切り替える

## 会話

- **AI-004**: AI は複数ターンの会話で文脈を維持する。チャット履歴はセッション内（ページ遷移後も）保持し、Firestore へは永続化しない
- **AI-005**: ユーザーは「会話をリセット」操作で履歴・提案状態をすべて初期化できる
- **AI-006**: AI の応答はストリーミングで逐次表示する
- **AI-007**: AI の対応範囲はアプリ関連（スケジュール・タスク・コラボの登録サポート、既存タスクの照会・編集、スケジュール照会、チームデータへの質問、アプリの使い方）に限定し、無関係な話題には定型の断りメッセージのみを返す
- **AI-008**: スケジュール照会（今日・今週・来週・週末等）に対しては、コンテキストのスケジュール一覧から該当期間を抽出して日付・時刻順に回答する。空き時間照会は 9:00〜23:00 を活動時間として回答する

## コンテキスト

- **AI-009**: AI へのコンテキスト（タスク・スケジュール・コラボ・メンバー・タスク列・メンバーの予定）はクライアントがアクティブチームのストアから組み立て、リクエストボディで API へ渡す。サーバーサイドでは Firestore へ直接アクセスしない
- **AI-010**: コンテキストにはメンバーの予定（`MemberCalendarEvent`、schedule カテゴリ参照）を含められる
- **AI-017**: コンテキストのタスク一覧にはタスク ID と説明文（200 字で切り詰め）を含め、AI が既存タスクを一意に参照・照会できるようにする
- **AI-018**: タスク詳細モーダルの「AIに相談」ボタン（編集モード・編集権限ありのみ）から、対象タスクをピン留めした状態で `/chat` へ遷移できる。ピン留め中は入力欄上にチップを表示し（✕ で解除）、対象タスクの説明文全文をシステムプロンプトへ注入する。対象を明示しない編集依頼はピン留めタスクへの更新として扱う。ピン留めは会話リセットで解除される

## 提案と登録

- **AI-011**: AI が `%%PROPOSAL%%`〜`%%/PROPOSAL%%` ブロック（JSON）を返した場合、UI は解析して提案カードを表示する。提案タイプは `schedule` / `task` / `collab` / `task_update` の 4 種。1 応答に複数の提案ブロックを含められる
- **AI-012**: 提案カードの「登録する」ボタン、または肯定応答テキスト（「OK」「はい」「登録して」等の定型パターン）で登録を実行する
- **AI-013**: 登録は既存リポジトリ関数（`createSchedule` / `createTask` / `createCollabSession` / `updateTask`）を経由してクライアント SDK で行い、Firestore セキュリティルールによる権限チェックを受ける
- **AI-014**: 提案内の人名（`participantNames` / `assigneeName`）はメンバーの `displayName` から UID へ、タスク列名（`columnName`）は列 ID へ登録時に解決する
- **AI-019**: `task_update` 提案は既存タスクの部分更新を表す。`taskId`（コンテキストのタスク一覧に記載の ID）と `changes`（title / description / dueDate / assigneeName / columnName のうち変更するフィールドのみ、最低 1 つ）を持つ。提案カードには変更前 → 変更後の差分を表示し、確定時に `changes` のフィールドのみを書き換える（名前・列名が解決できないフィールドは変更しない）。既存タスクへの編集依頼には新規作成ではなく `task_update` を使う

## API・運用条件

- **AI-015**: AI API（`POST /api/ai/chat`）は Anthropic Claude（haiku モデル）を使用する。`ANTHROPIC_API_KEY` 未設定時は HTTP 503 を返す
- **AI-016**: システムプロンプト生成（`generateSystemPrompt`）と提案ブロック解析は共通ユーティリティ（`src/lib/ai/`）に切り出し、Web チャットと Discord ボット（integration カテゴリ）の双方から利用する
