# notification

通知カテゴリの詳細仕様です。

このディレクトリを、通知カテゴリ定義・アプリ内通知・プッシュ通知・通知設定・配送先管理・既読管理に関する唯一の詳細仕様として扱います。

## 対象範囲

- 通知カテゴリ定義
- アプリ内通知
- プッシュ通知
- 通知設定
- 通知配送先エンドポイント
- 既読管理

## 対象外

- タスク・スケジュール・コラボ・チームで何を通知トリガーとするかの業務条件
- LIGHT / PARTY の料金体系やアップグレード条件
- 認証方式やアカウント本体の保持方針
- 通知 UI のレイアウトや共通ナビゲーションの見た目

## 他カテゴリとの境界

### task / schedule / collab / team との境界

- notification は各カテゴリで発生したイベントを通知へ変換するが、イベント発生条件や対象データの意味づけ自体は各カテゴリを参照する

### user との境界

- notification は user 配下にサブリソースを持てるが、認証状態やプロフィール本体は user を参照する

### plan との境界

- notification はプラン別の受信可否を適用するが、LIGHT / PARTY の定義と制限値自体は plan を参照する

### ui / platform との境界

- notification は通知データと配送を扱い、一覧・ドロップダウンの見た目は ui、端末配布やオフライン挙動は platform を参照する

## 読む順番

1. この README: notification カテゴリが持つ責務と境界を把握する
2. [requirements.md](./requirements.md): 通知機能の規範要件を確認する
3. [model.md](./model.md): Notification と配送先・設定データの保持方針を確認する
4. [flows.md](./flows.md): 生成、配信、既読化、設定変更の流れを確認する

## 採用する後続仕様

- 現時点で通知カテゴリ固有の後続仕様分割はない
- 後続仕様が追加されるまでは、このディレクトリ内の最新記述を正とする
- プラン別受信制約は plan カテゴリの最新定義に追従する
