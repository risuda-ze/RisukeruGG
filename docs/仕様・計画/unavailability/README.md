# unavailability（対応不可時間）

対応不可時間カテゴリの詳細仕様です。機能識別 ID は `UN`。

このディレクトリを、所属者が申告する「対応不可」の時間帯の入力・保存・一覧表示と、時間帯に付けるコメントに関する唯一の詳細仕様として扱います。

背景・経緯・実装の分割は変更仕様 [unavailability.md](../../変更仕様/unavailability.md) を参照してください。

> **実装状況**: 土台、閲覧、入力、CSV・定期入力、時間帯フィルタは実装済み（2026-11-20 時点）。コメント（UN-030〜UN-039）は未実装で、現行の実装は本人だけが書けるメモ（月ドキュメントの `notes`）になっている。実装と食い違いが出た場合は、変更する PR で本書を更新する。

## 対象範囲

- 対応不可時間の申告（1 時間単位。ドラッグ入力・CSV 取り込み・定期入力）
- 所属者の任意の時間帯に、全所属者が付けられるコメント
- 全所属者の対応不可を日単位で並べる一覧と、時間単位で見る所属者詳細
- 時間帯フィルタ（その時間帯に誰も不可でない日のハイライト）
- 保存期間（当月の前後 1 ヶ月）と古いデータの削除
- 退出・Kick・アカウント削除時の対象ユーザーのデータ削除

## 対象外

- チーム予定（`ScheduleEntry`）。対応不可の画面には重ねない。スケジュール画面にも対応不可を重ねない
- Google カレンダーの予定の取り込み。対応不可は本人の手入力のみで、予定の内容は保存しない
- 未申告の催促・リマインド・通知。申告の管理はしない
- 本人以外による対応不可時間の代理入力
- コメントへの返信（スレッド）と、コメントの通知

## 他カテゴリとの境界

### team との境界

- 行に並べる所属者とロールは team を参照する。画面では team と同じく「メンバー・スタッフ」と表記する
- 退出・Kick の処理本体は team が持ち、本カテゴリは「そのとき対象ユーザーの対応不可を消す」ことだけを定める

### schedule との境界

- 対応不可はチーム予定と別のモデル・別の画面で、既存の `MonthCalendar` / `WeekCalendar` は流用しない

### user との境界

- アカウント削除の処理本体は user が持ち、本カテゴリは所属していた全チームの対応不可を消すことだけを定める

### ui との境界

- サイドバー・「その他」ドロワーへの項目追加は ui の正本に従う。部品と見た目は `docs/DESIGN.md` に従う
