# schedule

スケジュール管理カテゴリの詳細仕様です。

このディレクトリを、チーム内スケジュールの作成・編集・表示、Google カレンダー書き出し、スケジュール詳細 UI、カレンダー UI 改善に関する唯一の詳細仕様として扱います。

## 対象範囲

- スケジュール CRUD
- 既存スケジュールを参照した複製新規作成
- カレンダー表示
- Google カレンダー書き出し
- スケジュール詳細 UI
- カレンダー UI 改善
- 終日入力、終了時刻補完、下書き復元

## 対象外

- チームロールの定義、アクティブチーム切り替え、所属管理
- タスクボードの管理、完了率集計
- カテゴリ（タスク・スケジュール共通）の追加・編集・削除。schedule は `categoryId` によるカテゴリ参照のみを扱い、管理機能は task を参照する
- Google ログイン自体の認証方式とセッション管理

## 他カテゴリとの境界

### team との境界

- schedule は `participantIds` を通じて参加メンバーを扱うが、所属管理やロール定義は team を参照する

### task との境界

- schedule はタスクとの関連情報を扱うが、タスク進捗の意味づけやボード管理は task を参照する
- schedule は `categoryId` によるカテゴリ参照を扱うが、カテゴリ（タスク・スケジュール共通）の定義・管理は task を参照する

### integration との境界（通知）

- schedule は開始前リマインダーの対象となる開始日時を持ち、Discord への配送と通知設定は integration を参照する

### user / platform との境界

- schedule は Google カレンダー書き出しを扱うが、認可の取得方法・認証状態や端末・PWA 前提は user / platform を参照する
