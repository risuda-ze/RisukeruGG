# schedule flows

## スケジュール新規作成フロー

1. メンバーまたはスタッフがカレンダーの日付セル、時間帯、または新規作成導線から作成を開始する
2. フォームにタイトル、開始日時、終了日時、プラットフォーム、説明、参加メンバーを入力する
3. 開始日時を入力した時点で終了日時が未設定なら、UI は 2 時間後を既定値として補完する
4. 終日として登録する場合は `allDay` を有効にし、保存時に開始・終了を同日の 00:00:00 に統一する
5. 保存時に `teams/{teamId}/schedules/{scheduleId}` へ反映し、チームの全所属者へリアルタイム配信する
6. 保存完了後、週ビュー / 月ビューの該当位置に新規エントリを表示する

## スケジュール複製新規作成フロー

1. メンバーまたはスタッフが既存スケジュールの詳細モーダルを開く
2. 詳細モーダルの複製新規作成導線から、新規スケジュール作成を開始する
3. 新規作成フォームに `title`、`startAt`、`endAt`、`allDay`、`platform`、`description`、`participantIds` を初期値として引き継ぐ
4. 複製起点の新規作成では、通常の未確定下書きよりも参照元から生成した初期値を優先して表示する
5. ユーザーは必要な項目を編集し、保存を実行する
6. 保存時に新しい `scheduleId` で `teams/{teamId}/schedules/{scheduleId}` を作成し、`version` は新規値として扱う
7. 参照元スケジュールとの恒久的なリンクは保持せず、週ビュー / 月ビューに別エントリとして反映する

## スケジュール編集フロー

1. ユーザーがカレンダー上の既存エントリを開き、詳細モーダルまたは編集フォームを表示する
2. 必要な項目を更新する
3. 説明は閲覧時に `MarkdownView`、編集時に `Textarea` で扱う
4. 複製新規作成導線から新規作成を開始した場合は、現在の編集対象ではなく別スケジュールの作成フローへ遷移する
5. 保存時に `version` を用いて競合検知を行い、更新後の内容を再描画する

## 下書き保存・復元フロー

1. ユーザーがフォームを開いた状態で入力を進める
2. 「確定」以外の操作でフォームを閉じた場合、入力内容をローカル下書きとして保存する
3. 次回同じ作成導線または編集導線を開いたとき、保存済みの下書きがあれば復元候補として読み込む
4. ユーザーが確定保存した場合、該当下書きは破棄する

## Google カレンダー書き出しフロー

1. ユーザーがスケジュール画面（PC はヘッダーのボタン、モバイルは ⋯ メニュー）から「Google カレンダーに書き出す」を実行する
2. `calendar.app.created` スコープの Google 認可ポップアップを開き、アクセストークンを取得する（[user/flows.md](../user/flows.md) 参照。トークンは保存しない）
3. `users/{uid}.googleCalendarExports.{teamId}.calendarId` のカレンダーが Google 側に実在すればそれを使う。無ければ副カレンダー「RisukeruGG - {チーム名}」を作成し、予定を書き込む前に `calendarId` を保存する
4. 専用カレンダー上のイベントを一覧し、`risukeruScheduleId` でチームの対象予定（当日 0:00（JST）より後に終了する予定）と突き合わせる
5. Google 側に無い予定は追加し、内容が違う予定は上書きする。RisukeruGG 側に無くなった予定は、当日 0:00（JST）より後に終了するものだけ削除する。`risukeruScheduleId` を持たないイベントには触れない
6. すべて成功したら `exportedAt` を更新し、追加・更新・削除の件数を表示する

## Google カレンダー書き出し失敗フロー

1. 同意の拒否、トークン取得失敗、API エラーのいずれかが発生する
2. スケジュール画面にエラーを表示する。一部の予定だけ失敗した場合は失敗件数を表示する。いずれの場合も `exportedAt` は更新しない
3. ユーザーは同じ操作で再実行する（冪等なので途中まで書き出された状態からでも整合する）

## カレンダー表示フロー

1. ユーザーが週ビューまたは月ビューを選択する
2. 表示は日曜始まりで組み立てる
3. 同時間帯または同日の複数エントリは重複が分かるように配置する
4. 複数日イベント、単日イベント、終日イベントをそれぞれの表示ルールで描画する
