# platform

PWA・オフラインカテゴリの詳細仕様です。

このディレクトリを、PWA 配布・ホーム画面追加・Service Worker・オフライン閲覧・接続断時の扱い・バージョン表示とリリースノートに関する唯一の詳細仕様として扱います。

> **実装状況**: バージョン表示とリリースノート（PF-004〜PF-011）は未実装。背景・仮決定・実装内容は変更仕様 [release-notes.md](../../変更仕様/release-notes.md) を参照する。実装と食い違いが出た場合は、実装 PR で本書を更新する。

## 対象範囲

- PWA 配布
- ホーム画面追加
- Service Worker
- オフライン閲覧
- 接続断時のユーザー通知
- バージョン表示とリリースノート（公開ページ `/release-notes`、コード内に持つ原稿、GitHub Releases に置く下書き、バージョンの上げ方）

## 対象外

- 通知カテゴリごとの配信条件や既読管理
- 認証方式やセッション維持
- タスク / スケジュール / コラボ各データの業務ルール
- 画面ごとの見た目やナビゲーション構造

## 他カテゴリとの境界

### notification との境界

- platform は通知を受け取る実行環境と配布形態を扱い、通知カテゴリ定義・受信設定・既読管理は notification を参照する

### user との境界

- platform は認証状態を保持せず、セッション状態や外部連携用の認証情報は user を参照する

### task / schedule / collab との境界

- platform は各データの業務意味や更新ルールを決めず、オフライン時の取得・表示・制御だけを扱う

### ui との境界

- platform はオフライン関連の動作前提を定義し、バナーやプロンプトの具体的な見た目は ui を参照する
- リリースノートはナビゲーション項目を持たない。入口は個人設定「アプリ情報」のバージョン表示と LP フッターで、platform が定める

## 読む順番

1. この README: platform カテゴリの責務と他カテゴリとの境界を把握する

- 後続仕様が追加されるまでは、このディレクトリ内の最新記述を正とする
- PWA とオフラインの実装差分は platform カテゴリの最新記述を優先する
