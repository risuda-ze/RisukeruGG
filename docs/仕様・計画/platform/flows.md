# platform flows

## 今後詳細化するフロー

### PWA インストールフロー

- インストール可能判定
- プロンプト表示
- ユーザー選択
- ホーム画面追加

### オフライン閲覧フロー

- 通信断検知
- キャッシュ読込
- 閲覧継続
- 書き込み時メッセージ表示

## リリースノート閲覧フロー（未実装・Issue #216）

1. ユーザーが個人設定の「アプリ情報」タブを開く
2. システムが `v{version}` を表示する
3. ユーザーがバージョンをクリックする
4. システムが `/release-notes` を別タブで開き、全バージョンを新しい順に表示する

未ログインの閲覧者は LP フッターの「リリースノート」または URL の直接入力で同じページを開く。ログインは求めない。

## リリース時の原稿更新フロー（未実装・Issue #216）

1. 開発者が `develop` から `feature/release-v{version}` を切る
2. `package.json` の `version` を上げ、`src/lib/releaseNotes.ts` の先頭に 1 件追加する
3. ユニットテストが先頭のバージョンと `package.json` の一致を確認する
4. `develop` へマージしたうえで、`develop` → `main` のリリース PR を作る

利用者に見える変更が無いリリースでは 1〜3 を行わない。
