# platform flows

## 今後詳細化するフロー

### PWA インストールフロー

- インストール可能判定
- プロンプト表示
- ユーザー選択
- ホーム画面追加

### オフライン閲覧フロー

- 通信断検知
- キャッシュ読込
- 閲覧継続
- 書き込み時メッセージ表示

## リリースノート閲覧フロー（未実装）

1. ユーザーが個人設定の「アプリ情報」タブを開く
2. システムが `v{version}` を表示する
3. ユーザーがバージョンをクリックする
4. システムが `/release-notes` を別タブで開き、公開済みの Release を新しい順に表示する

未ログインの閲覧者は LP フッターの「リリースノート」または URL の直接入力で同じページを開く。ログインは求めない。

ページの内容は、サーバーが GitHub Releases から取得して 1 時間ごとに作り直したものを返す。閲覧のたびに GitHub へ問い合わせることはしない。

## リリースノートの原稿更新フロー（未実装）

1. 開発者が利用者に見える変更を `develop` へマージするたびに、GitHub の下書き Release（次回分を 1 件だけ持つ）に 1 行足す
2. リリース時、開発者が `develop` 向けの PR で `package.json` の `version` を上げる
3. `develop` → `main` のリリース PR をマージする
4. 開発者が下書き Release のタグを `v{version}`、Target を `main` にして公開する
5. システムが 1 時間以内に `/release-notes` へ反映する

利用者に見える変更が無いリリースでは 2 と 4 を行わない。公開済みの Release は、誤記の訂正を除いて書き換えない。
