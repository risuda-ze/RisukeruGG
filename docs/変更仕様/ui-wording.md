# UI 文言・操作の統一規約 変更仕様

**作成日**: 2026-11-18
**状態**: 規約確定（一部仮決定）・画面は未適用（Issue #207）
**正本**: [docs/仕様・計画/ui/requirements.md](../仕様・計画/ui/requirements.md)（UI-033〜UI-042）、[docs/共通用語/共通用語.md](../共通用語/共通用語.md)（操作ラベル）

## 背景・目的

画面ごとにボタンの言葉（保存 / 作成する / 新規追加 / 追加）、閉じ方（閉じる / 戻る / キャンセル）、削除確認の出し方、空状態・ローディング・エラーの文言がそろっていない。規約を先に決め、後続の実装 PR で全画面を合わせる。

## 全体方針

- **本 PR は規約のみ。** 画面のコードは変更しない。正本（UI-033〜042）は実装より先に書くため、実装 PR がマージされるまで正本と現行画面に差がある
- **多数派に寄せる。** 現状調査（下記）で件数の多い表現を規約にし、直す箇所を減らす
- **言葉の定義は共通用語、使い方の規則は ui/requirements に書く。** 本書は経緯・現状調査・実装の分割を管理する
- **対象は保護ルート配下と `/collab/[token]` の画面文言。** LP（`src/app/page.tsx`）、規約類のページ、Discord Bot・メールの文面、AI の応答文は対象外
- **ロールの表示名は扱わない。** #219（メンバー / スタッフ）に委ねる

## 着手条件

- 画面への適用は #178 の Modal / Toast 置き換え後に行う（同じファイルを触るため）。2026-11-18 時点の `develop` には `Modal`（Dialog / Drawer）と sonner の `Toaster` が入っているが、`toast` を使う画面は 1 ファイルだけ
- 本書と正本の作成は #178 を待たない
