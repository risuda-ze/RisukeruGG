RisukeruGG テーマ比較 — Light（v3）と Dark（導出）

ライトの各トークンから、色相を保ったまま OKLCH の明度を反転して導出した参考値。GitHub / Linear / Notion / Material のライト↔ダーク対応に倣った規則:

  • 面は「暗 → 明」で段を積む（canvas → surface → card → surface-2）。ライトの「白が最前面」をダークでは「最も明るい紫黒が最前面」に置き換える
  • 枡線は面より明るくする（ライトは面より暗い）。影なしの方針はそのまま、段差と枡線で奥行きを出す
  • 文字は Deep Iris / Amethyst の色相を保った明るいラベンダーに。コントラストは 4.5:1 以上を再計測
  • プライマリは 1 段明るく（白文字 4.5:1 を満たす上限 L=0.58）。danger は明るくすると白文字が足りないため、ダークでは文字を canvas 色にする
  • ファミリーの border は L 0.72 に揃えて 1 段明るく、tint は border を canvas に 22% 混ぜた低彩度面、text は L 0.84
