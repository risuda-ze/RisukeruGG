# RisukeruGG 共通用語

このドキュメントは、仕様書で共通して使用する用語の定義をまとめたもの。

## ユビキタス言語

| 用語               | 定義                                                                                           |
| ------------------ | ---------------------------------------------------------------------------------------------- |
| **LIGHTプラン**    | アプリが提供する無料プラン。                                                                   |
| **PARTYプラン**    | アプリが提供する有料プラン。                                                                   |
| **LIGHTユーザー**  | LIGHTプラン（無料）を利用しているユーザー                                                      |
| **PARTYユーザー**  | PARTYプラン（有料）を利用しているユーザー                                                      |
| **チーム（TEAM）** | 複数のユーザーが連携する単位。チームコードを入力することでチームに参加できる                   |
| **チームコード**   | チームへの参加に使用する固有の英数字コード。Owner/Editor が設定画面から確認・リセットできる    |
| メンバー（MENBER） | チームの主要なメンバーが設定されるロール。主要な機能の編集権限の他、チームの管理者権限を持つ。 |
| スタッフ（STAFF）  | 一部の機能において編集ができるロール。                                                         |
