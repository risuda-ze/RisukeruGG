# RisukeruGG 共通用語

このドキュメントは、仕様書で共通して使用する用語の定義をまとめたものです。

## ユビキタス言語

| 用語                 | 定義                                                                                        |
| -------------------- | ------------------------------------------------------------------------------------------- |
| **LIGHTユーザー**    | LIGHTプラン（無料）を利用しているユーザー                                                   |
| **PARTYユーザー**    | PARTYプラン（有料）を利用しているユーザー                                                   |
| **チーム（TEAM）**   | ゲーム配信者グループ。チームコードを入力することでチームに参加できる                        |
| **チームコード**     | チームへの参加に使用する固有の英数字コード。Owner/Editor が設定画面から確認・リセットできる |
| **LIGHTプラン**      | 無料プラン。チームメンバー上限 2 名、タスク月 5 件、コラボ月 3 件等の制限あり               |
| **PARTYプラン**      | 有料プラン。全機能無制限、バナー広告なし                                                    |
| **Owner**            | チームの全権限を持つロール。チーム作成者が自動付与される                                    |
| **Editor**           | スケジュール・タスクの作成・編集ができるロール。チームコードで参加したユーザーに付与        |
| **Viewer**           | 閲覧のみ可能なロール。Owner が設定から変更できる                                            |
| **ソロチーム**       | 初回ログイン時に自動生成される自分だけのチーム                                              |
| **コラボセッション** | コラボ日程調整の単位。`open` / `confirmed` / `cancelled` / `expired` のステータスを持つ     |
| **ブリーフ（1枚紙）** | タスク管理 v2 の親エンティティ。動画・配信 1 本を表し、見出し（公開予定日・出演者・概要）と工程一覧を持つ |
| **工程**             | ブリーフに属する作業単位。担当・締切・状態・工程固有の入力項目・やり取りを持つ。状態は待機 / 着手可能 / 作業中 / 完了 / スキップ |
| **進め方（プレイブック）** | チーム固有の工程の型。新しいブリーフはここから工程・担当・締切が埋まった状態で生成される。対話で引き出し、運用から育てる |
| **単発タスク**       | ブリーフに属さない作業（機材購入など）。既存カンバンのタスクを指す                          |
| **差分（変更の記録）** | ブリーフ・工程に対する変更の記録（`briefEvents`）。ダイジェストと学習の入力になる          |
| **入力待ち**         | 着手可能・作業中なのに必須の入力項目が埋まっていない工程の状態                              |
| **操作層**           | ブリーフ操作を「権限判定 → 読み込み → 計画 → 差分記録 → commit」で一か所に定義したもの。Web・Discord・AI・公開 API が共有する |

## 操作ラベル（UI 文言）

画面のボタン・メニュー・ダイアログで使う動詞の定義。使い方の規則（ラベルの形、確認ダイアログ、通知の文言）は `docs/仕様・計画/ui/requirements.md` の UI-039〜UI-048 を参照する。画面側は未適用（#207）。ロールの表示名は #219 で扱う。

| 用語           | 定義                                                                                                                             |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| **作成**       | それ自体が詳細画面や子を持つ単位を新しく作る。対象: チーム、ブリーフ、進め方、コラボ調整                                         |
| **追加**       | 既にある一覧・ボード・カレンダー・親に項目を足す。対象: タスク、予定、工程、カテゴリ、ステータス、定型指示、参加者、候補日       |
| **保存**       | 既存データへの変更を確定する。新規の確定には使わない（作成 / 追加を使う）                                                        |
| **変更**       | 選択肢を切り替えて即時に反映する。対象: ロール、アクティブチーム、通知チャンネル。入力フォームの確定には使わない（保存を使う）   |
| **削除**       | データを消す。元に戻せないため必ず確認ダイアログを出す。コラボ調整の取りやめも操作ラベルは「削除」とする                         |
| **解除**       | 連携・固定・ピン留めなどの関係を外す。データそのものは消さない                                                                   |
| **キャンセル** | 入力や確認を破棄してダイアログ・フォームを閉じる。単独では業務上の取りやめの意味に使わない                                       |
| **閉じる**     | 変更を伴わない表示（閲覧のみのダイアログ、ヒント、バナー）を閉じる                                                               |
| **戻る**       | 前の画面・前の手順へ移動する。ダイアログを閉じる意味には使わない                                                                 |
