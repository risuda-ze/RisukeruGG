# PR #282 最終レポート

## 概要

エージェント用スクリプトが Windows で失敗する不具合 2 件（#239: Issue 起票、#245: 最終レポート投稿のコミットメッセージ）の修正。原因は共通で、`scripts/agent/lib.mjs` の `sh()` が Windows でシェル経由（`shell: true`）で起動し、空白を含む引数が分割されていたこと。

- `sh()` はシェルを介さず `gh` / `git` を直接起動する。コマンドを起動できない場合は `allowFail` を指定していても例外にする
- `scripts/agent/file-issue.mjs` は Issue の本文を一時ファイルに書いて `--body-file` で渡す（引数のままだと Windows のコマンドライン長の上限、約 32,000 文字で失敗する）
- `tests/unit/agent/sh.test.ts` を追加（3 件）

変更ファイルは上記 3 つ（+37 / -5 行）。画面の変更、lint / E2E 定義の変更は無い。マージで #239 と #245 が閉じる。

このレポートは、develop へのリベース後の HEAD `d885ac2` に対するもの。リベース前の HEAD `d2d404a` に対する最終レポートが先に投稿されているが、内容の差は無い（下記）。
