## 人が確認すべき点

- Q-1（任意）: 残った一時ワークツリーを見分ける処理は、tmpdir のパスを文字列で比べている。macOS のように tmpdir がシンボリックリンクの環境では一致せず、外せない可能性がある（未検証）。その場合も例外で失敗が表に出るので、問題が隠れることはない。レポート投稿を Windows 以外で動かす予定があるかどうかで、対応の要否を判断してほしい
- guard hook のヒアドキュメント判定は行単位の簡易な解析で、複数行にまたがる引用符や算術式の `<<` は誤認しうる。上限はコード中の `ponytail:` コメントに書いてある。エージェントが書く形では起きない前提
