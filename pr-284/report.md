## 人が確認すべき点

- 空の Emulator での 1 回目の実行（Issue #238 の再現手順そのもの）は、レビュー側では実行していない。レビュー環境で Emulator の再起動ができなかったため。作者は PR 本文で実施済み（シード全体が約 7 秒で完了、6 人ともシードの値）と記録しているが、一次・二次とも再実行していない。確認する場合の手順:
  1. Emulator を止め、`.emulator-data/` が無い状態にする
  2. `pnpm emulators` を起動する
  3. `node scripts/seed.mjs` を 1 回だけ実行する
  4. エラー無く終わり、6 人の `currentTeamId` がシードの値（teamAlpha ×5、里奈は teamBeta）で、ソロチームを指すユーザーがいないことを確認する
- 上限の 60 秒は、トリガーの初回起動がこれより遅い環境ではシードがエラーで止まる値である（データが壊れるのではなく、止まる）。手元の環境で上記の手順が 60 秒以内に終わるかを見ておくとよい
