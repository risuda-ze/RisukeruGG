# Feature Spec: スケジュール管理カレンダー UI 改善

**Branch**: `007-schedule-calendar-ui-improvements`
**Date**: 2026-05-20
**Feature ID**: 007

## 概要

スケジュール管理画面（MonthCalendar）および詳細モーダル（ScheduleDetailModal）に対して、表示品質・操作性・ブラウザ互換性の一連の改善を行う。

---

## 変更要件

### C-1: ヘッダーの「予定を追加」ボタン廃止
`schedule/page.tsx` の TopBar 内に配置されている「予定を追加」ボタンを削除する。
日付クリックによる新規作成（`onDateClick`）は引き続き有効とする。

### C-2: タイトル欄と曜日表示欄の結合
MonthCalendar の曜日ヘッダー行（SUN/MON/...）と各セルの日付番号エリアを視覚的に統合し、よりシームレスに表示する。
- 独立した曜日ヘッダー行は維持し、`py-2 → py-1` に高さ削減
- ナビバーの `border-b` を除去して曜日ヘッダーと視覚的に連続させる（月表示時）

### C-3: タイトル欄の高さ縮小
日付番号エリアの高さ（`DATE_H`）を縮小し、イベントカードの表示領域を広げる。

### C-4: 予定カードのフォントサイズ拡大
単日カード（`text-[10px]`）・複数日バー（`text-[11px]`）を各1〜2段階拡大する。

### C-5: 複数日予定カードのテキスト左揃え
複数日イベントバー中央のタイトルスパンを `text-center` から `text-left` に変更する。

### C-6: 詳細モーダルの「説明」プレビュー機能削除
`ScheduleDetailModal` の説明フィールドから MarkdownEditor（プレビュー/編集切替）を廃止し、プロジェクト標準パターンに倣った `Textarea` コンポーネント（新規作成）を使用する。
- 編集時: 新規 `Textarea` コンポーネント（`Input.tsx` と同パターン）
- 閲覧時: `MarkdownView`（`MarkdownEditor.tsx` からエクスポートした読み取り専用レンダラー）で Markdown 表示

### C-7: 詳細モーダルのドラッグ＆リサイズ
`ScheduleDetailModal` のポップアップをマウス操作で移動・サイズ変更できるようにする。
- ヘッダー部分のドラッグで移動
- 右下コーナーにリサイズハンドルを配置（SVG グリップ記号で視覚的に示す）
- 外部ライブラリは使用せず、PointerEvents API（`setPointerCapture`）で実装
- 初期位置: 画面中央（モーダルを開くたびに毎回リセット）
- PC（マウス操作）のみ対応。モバイル（タッチデバイス）では従来の固定表示を維持

## 修正要件

### F-1: 複数日カードの余白を単日カードに統一
現在、複数日イベントバーは日付セル境界ギリギリに配置されている。単日カードのコンテナが持つ `px-1`（4px）と同等の余白を複数日バーにも適用する。
- `left: calc(leftPct + 4px)` / `width: calc(widthPct - 8px)` の形で調整
- ただし行継続バー（startsBefore/endsAfter）は境界側の余白を0にする

### F-2: Edge での日付入力表示修正
`DateTimeInput` コンポーネントの `type="datetime-local"` 入力がブラウザ（Edge/Chrome）によって表示書式が異なる問題を根本解決する。
- `type="datetime-local"` を廃止し、`type="date"` と `type="time"` の 2 input に分割
- `onChange` で両値を合成して `Date` オブジェクトに変換
- `allDay` モード時は `type="time"` を非表示

### F-3: 予定カードに日程を表示しない
複数日イベントバーの日付（`MM/dd`）表示を削除し、時間（`HH:mm`）とタイトルのみにする。
- `startsBefore` の場合: `◀` + タイトルのみ
- 通常開始: アイコン + `HH:mm` + タイトル

### F-4: 複数日カードの「+n件」オーバーフロー表示
`MAX_TRACKS = 2` を超えた複数日イベントを非表示にするのではなく、各日付セルに「+n件」バッジを表示する。
- 複数日イベントの並べ替えを期間の長い順（降順）に変更
- 単日イベントは開始時間の早い順（既存）を維持
- 各日付セルで非表示になった複数日イベント数をカウントして表示
- 「+n件」バッジはクリック不可のテキスト表示のみ（インタラクションなし）

## Clarifications

### Session 2026-05-20

- Q: 「+n件」バッジはクリック可能にしますか？ → A: クリック不可・テキスト表示のみ（インタラクションなし）
- Q: C-7 ドラッグ/リサイズはモバイル（タッチデバイス）でも動作させますか？ → A: PC（マウス）のみ対応。モバイルは固定表示を維持
- Q: C-2 曜日ヘッダー行の統合方法は？ → A: 独立行を維持・高さ削減（py-2→py-1）でシームレスに見せる
- Q: C-7 モーダルを閉じて再度開いたとき位置はリセットするか？ → A: 毎回画面中央にリセット
- Q: F-2 Edge 日付修正のアプローチは？ → A: `date` + `time` の 2 input に分割（ブラウザ非依存の根本解決）

---

### F-5: ホバーツールチップのサイズ・位置修正
- `PANEL_W` を 240 → 360 に拡大（1.5倍）
- 位置: ホバー Y 座標が画面の下半分なら上方向（tooltip.y - panelH）、上半分なら下方向（tooltip.y）に表示

## 追加変更（2026-05-20 レビュー後）

### A-1: カレンダーグリッドの背景色を黒寄りに変更
MonthCalendar のグリッドコンテナ背景を `bg-surface`（#11112a）から `bg-bg`（#0a0a18）に変更し、文字視認性を向上させる。

### A-2: 詳細モーダルのリサイズハンドル視覚化
リサイズハンドル（右下コーナー）に SVG グリップ記号（2本の斜線）を表示し、操作可能であることをユーザーに伝える。

### A-3: 詳細モーダルの説明を Markdown レンダリング
閲覧時のプレーンテキスト表示（`whitespace-pre-wrap`）を `MarkdownView` による Markdown レンダリングに変更する。
編集時は `Textarea`（C-6 で実装済み）を引き続き使用する。
