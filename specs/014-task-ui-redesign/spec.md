## Clarifications

### Session 2026-06-03（/speckit-clarify）

- Q: モバイルブレークポイントの正規定義（375px vs 390px） → A: **390px**（iPhone 14 標準幅。Clarifications・SC と整合させる）
- Q: 緊急度チップ「soon」の閾値（何日前から警告？） → A: **2日以内**（明日・明後日のみ。厳格な直前アラート）
- Q: MobileToolbar の配置方針（AppShell 修正 vs tasks ページ直挿入） → A: **AppShell を修正**して tasks/page.tsx が AppShell 内に収まるようにする
- Q: モバイル詳細フォームの表示方式（ページ遷移 vs オーバーレイ） → A: **フルスクリーンオーバーレイ**（URL変更なし。TaskDetailModal をモバイルで全画面化。PC と共通コンポーネント）
- Q: D&D のスコープ（PC のみ vs 全ブレークポイント） → A: **PC（カンバン）のみ有効**。モバイルのリスト表示では D&D 無効、ステータス変更はピルタップで行う

### Session 2026-06-05（v4: 設定画面専用ルート・アイコン対応）

- `TaskControlBar` の設定ボタンが遷移する `/settings/tasks` ルートを新規作成する
- `TaskStatus` に `icon: string | null` フィールドを追加し、設定画面でアイコンを選択できるようにする
- `TaskCategory` に `icon: string | null` フィールドを追加し、設定画面でアイコンを選択できるようにする
- カンバン列ヘッダーのカラーバー直後にステータスのアイコンを表示する
- `TaskControlBar` のカテゴリバッジと `TaskCard` のカテゴリチップにカテゴリアイコンを表示する
- `TaskDetailModal` のステータス・カテゴリ表示部分にアイコンを表示する

### Session 2026-06-04（v3: コントロールバー再設計）

- タスクページのカテゴリフィルタ行・ボードヘッダー行を廃止し `TaskControlBar` コンポーネントに統合する
- `TaskControlBar` 左側: カテゴリ選択バッジ（複数選択可）＋作業者選択プルダウン（単一選択）
- `TaskControlBar` 右側: タスク件数・タスク追加ボタン・ステータス/カテゴリ設定ボタン・`?`ボタン
- CSV出力機能を廃止（ボタン・importともに削除）
- カンバン末尾の「＋ ステータス列を追加」ゴーストカラムを削除
- カンバン列幅を固定304pxから動的均等分割（`flex: 1 1 0` + `min-width: 180px`）に変更
- タスクカードフッターの表示順を「締め切り日時 → 担当者 → 緊急度バッジ」に変更。日付は `M/d HH:mm` 形式
- Q: TaskControlBar のモバイル (390px) での表示方式 → A: **1行横スクロール**（PC と同レイアウト。左エリアを `overflow-x-auto scrollbar-none` で横スクロール可能にする）
- Q: 担当者フィルタのプルダウン候補リスト範囲 → A: **チームの全メンバー**を常に表示（タスク割り当て有無に関わらず。既存の `members` prop を流用）

## User Scenarios & Testing

### User Story 1 — カンバンボードでタスクを確認する (Priority: P1)

ユーザーはタスク管理画面でステータス別にタスクをカンバン形式で確認できる。

**Acceptance Scenarios**:

1. **Given** タスク管理画面を開く（PC）, **When** 画面が描画される, **Then** ステータス列ごとにタスクカードが均等幅（`flex: 1 1 0`、最小幅 180px）のカラムで表示される
2. **Given** タスクカード, **When** 確認, **Then** カテゴリチップ・タイトル・担当者アバター・期限・緊急度チップ・編集/削除ボタンが表示される
3. **Given** 期限切れタスク, **When** カードを確認, **Then** 緊急度チップが赤で「N日超過」と表示される
4. **Given** 当日期限のタスク, **When** カードを確認, **Then** 緊急度チップが警告色で「今日まで」と表示される
5. **Given** 完了ステータスのタスク, **When** カードを確認, **Then** カードが opacity 0.82 で緊急度チップが「完了」（success色）で表示される
6. **Given** タスクカードにホバー, **When** 確認, **Then** カードが translateY(-2px) でボーダーが primary 色に変化する

---

### User Story 2 — カンバンに新しいタスクを追加する (Priority: P1)

**Acceptance Scenarios**:

1. **Given** タスク管理画面, **When** 「タスクを追加」ボタンをクリック, **Then** タスク追加モーダルが開く
2. **Given** カンバン列, **When** 列下部の「＋ タスクを追加」をクリック, **Then** そのステータスが選択済みでタスク追加モーダルが開く
3. **Given** モーダルが開いている（新規追加モード）, **When** フッターを確認, **Then** 「削除」ボタンは表示されない
4. **Given** モーダル（新規追加）, **When** タイトルを入力して「保存」をクリック, **Then** タスクが作成されモーダルが閉じる

---

### User Story 3 — タスク詳細を編集する (Priority: P1)

**Acceptance Scenarios**:

1. **Given** タスクカード, **When** クリック, **Then** 幅960pxの詳細モーダルが開き既存データが表示される
2. **Given** タスク詳細モーダル（編集モード）, **When** 確認, **Then** 左カラムに「タイトル・カテゴリ・ステータス・締切日時・説明」、右カラムに「コメント/メモ」が表示される
3. **Given** コメントパネル, **When** コメントが存在する, **Then** チャット形式（送信者アバター・名前・時刻・バブル）で表示される
4. **Given** コメント入力欄, **When** 確認, **Then** 丸型一行フィールド＋上向き矢印の送信ボタンで構成される（textarea ではない）
5. **Given** モーダルフッター, **When** 確認, **Then** 左に「削除」ボタン、右に「キャンセル」「保存」ボタンが表示される（「閉じる」のみは NG）
6. **Given** 新規追加モーダルのフッター, **When** 確認, **Then** 「削除」ボタンは非表示
7. **Given** 「保存」をクリック, **When** 処理完了, **Then** 変更が保存されモーダルが閉じる

---

### User Story 4 — モバイル (390px) でタスクを操作する (Priority: P1) ★ Critical

**Acceptance Scenarios**:

1. **Given** モバイル表示（390px）, **When** タスク管理画面を開く, **Then** 上部にステータスピル一覧、下部に選択中ステータスのタスクリストが表示される（カンバンは非表示）
2. **Given** ステータスピル, **When** 別のステータスをタップ, **Then** 対応するタスクリストに切り替わる
3. **Given** タスクカード（モバイル）, **When** タップ, **Then** TaskDetailModal がフルスクリーンオーバーレイ（URL変更なし）で表示される
4. **Given** モバイル表示, **When** タスク管理画面を確認, **Then** 画面下部に MobileToolbar が表示される
5. **Given** モバイル表示, **When** 「タスクを追加」ボタン（固定配置）をタップ, **Then** 新規タスク追加画面（詳細フォーム）に遷移する
6. **Given** モバイル詳細フォーム, **When** 確認, **Then** 入力カラムとコメントカラムが縦積みで表示される

---

### User Story 5 — タブレット (768px) で正しく表示される (Priority: P2) ★ New

**Acceptance Scenarios**:

1. **Given** タブレット表示（768px）, **When** タスク管理画面を開く, **Then** TopBar の subtitle テキストが縦方向にはみ出ない

**Acceptance Scenarios**:

1. **Given** 初回表示, **When** タスク画面を開く, **Then** 操作説明ヒントバーが表示される
2. **Given** ヒントバーが表示されている, **When** 「×」をクリック, **Then** バーが閉じ localStorage に状態が保存される
3. **Given** ヒントバーを閉じた, **When** 「?」ボタンをクリック, **Then** ヒントバーが再表示される

### User Story 7 — タスクをフィルタリングする (Priority: P1) ★ v3

**Acceptance Scenarios**:

1. **Given** TaskControlBar、**When** カテゴリバッジを複数タップ、**Then** 選択したカテゴリに属するタスクのみ表示される（OR条件）
2. **Given** TaskControlBar、**When** 全カテゴリバッジを解除、**Then** 全タスクが表示される
3. **Given** TaskControlBar、**When** 担当者プルダウンで特定の担当者を選択、**Then** その担当者が割り当てられたタスクのみ表示される
4. **Given** TaskControlBar 右側、**When** 確認、**Then** タスク件数・タスク追加ボタン・設定ボタン・?ボタンが右揃えで表示される
5. **Given** 画面、**When** 確認、**Then** CSV出力ボタンが存在しない
6. **Given** カンバンボード、**When** 確認、**Then** 末尾に「ステータス列を追加」ゴーストカラムが存在しない

### Edge Cases

- タスクが0件のカラムには「タスクはありません」の空状態が表示される
- タスクは期限が近い順（昇順）にソートされる
- カテゴリなしのタスクでもカードが正しく表示される（カテゴリチップ非表示）
- TaskDetailModal はモバイルでフルスクリーンオーバーレイとして表示され、2カラムレイアウトが縦積みに変化する
- TaskControlBar はモバイル (390px) でも常に表示される。左エリアは横スクロールでカテゴリバッジ・担当者プルダウンにアクセスできる

## Requirements

### Functional Requirements

- **FR-001**: タスクカードはカテゴリチップ（アイコン+ラベル）・タイトル・担当者アバター・期限・緊急度チップ・編集/削除ボタンを持つ
- **FR-002**: カンバン列は動的幅（表示領域をステータス数で均等分割・最小幅180px）で、ヘッダーにカラーバー・列名・件数・メニューボタンを持つ ★ v3変更
- **FR-003**: 各列の下部に「＋ タスクを追加」破線ボタンを配置する
- **FR-004**: ~~最右端に「＋ ステータス列を追加」ゴーストカラムを配置する~~ → **廃止** ★ v3変更
- **FR-005**: タスクページに `TaskControlBar` を配置する。左揃え: カテゴリ選択バッジ（複数選択可）・作業者選択プルダウン（単一選択）。右揃え: タスク件数・タスク追加ボタン・「ステータス・カテゴリ設定」ボタン・「?」ボタン。**モバイル (390px) でも同一の1行レイアウトを使用し、左エリアは `overflow-x-auto scrollbar-none` で横スクロール可能にする** ★ v3変更
- **FR-006**: 緊急度チップは over（赤）・today（警告）・soon（警告）・normal（グレー）・done（緑）の5状態を持つ。**soon は期限2日以内（today 除く）を閾値**とする
- **FR-007**: タスク詳細モーダルは幅**960px**・2カラムレイアウト（左：入力項目 / 右：コメント）で表示する
- **FR-008**: タスク詳細モーダルは新規追加・編集の両モードを単一コンポーネントで扱う（task?: Task）
- **FR-009**: コメントパネルはチャット形式（自分=右揃えバブル・相手=左揃えバブル）で表示する
- **FR-010**: コメント入力は**丸型一行フォーム**（border-radius: full）＋上向き矢印の送信ボタンで構成する
- **FR-011**: モーダルフッターは左に「削除（編集時のみ）」、右に「キャンセル」「保存」を配置する
- **FR-012**: ヒントバーは localStorage で非表示状態を永続化し「?」ボタンで再表示できる
- **FR-013** ★ New: **モバイル（md 以下）ではステータスピル＋縦リスト表示に切り替える**（カンバン非表示）
- **FR-014** ★ New: **タスクページのモバイルで MobileToolbar を表示する**（AppShell を修正し tasks/page.tsx を AppShell 内に収める）
- **FR-015** ★ New: **タブレット (768px) で TopBar の subtitle テキストが溢れない**ようにスタイルを調整する
- **FR-016**: 既存のドラッグ＆ドロップ機能（@hello-pangea/dnd）は **PC（カンバン表示）のみ**維持する。モバイルのリスト表示では D&D 無効とし、ステータス変更はピルタップで行う
- **FR-017**: 各カードは pop-scale アニメーションで出現する
- **FR-018**: モバイルのステータスプルダウンはモバイルレイアウト切替後は不要なので削除する
- **FR-019**: CSV出力機能を廃止する。`exportTasksCsv` ボタン・import・ユーティリティ関数をすべて削除する ★ v3追加
- **FR-020**: カテゴリフィルタを単一選択から**複数選択**に変更する（OR条件：いずれかのカテゴリに一致するタスクを表示。無選択は「すべて」と同義） ★ v3追加
- **FR-021**: 担当者（作業者）フィルタを追加する。プルダウン形式・単一選択・「すべて」オプション含む。**候補リストはチームの全メンバー**（タスク割り当て有無に関わらず表示。既存 `members` を使用） ★ v3追加
- **FR-022**: タスクカードのフッターを「締め切り日時（`M/d HH:mm`）→ 担当者アバター+名前 → 緊急度バッジ」の順に再構成する ★ v3追加
- **FR-023** ★ v4: `/settings/tasks` ルートを新規作成する。`TaskControlBar` の設定ボタンクリックでこのページに遷移する（現在は `/settings/tasks` が存在しない）
- **FR-024** ★ v4: `TaskStatus` インターフェースに `icon: string | null` フィールドを追加する。`/settings/tasks` のステータス設定UIでアイコンを選択できるようにする
- **FR-025** ★ v4: `TaskCategory` インターフェースに `icon: string | null` フィールドを追加する。`/settings/tasks` のカテゴリ設定UIでアイコンを選択できるようにする
- **FR-026** ★ v4: カンバン列ヘッダーのカラーバー直後に、ステータスのアイコンを表示する（`icon` が設定されている場合のみ）
- **FR-027** ★ v4: `TaskControlBar` のカテゴリバッジと `TaskCard` のカテゴリチップに、カテゴリアイコンを表示する（`icon` が設定されている場合のみ）
- **FR-028** ★ v4: `TaskDetailModal` のステータス・カテゴリ選択・表示部分に、アイコンを表示する（`icon` が設定されている場合のみ）

## Success Criteria

- **SC-001**: PC (1440px) でカンバン全列が均等幅（表示領域 ÷ ステータス数）で表示される ★ v3変更
- **SC-002**: タスクカードにカテゴリチップ・緊急度チップが正しく表示される
- **SC-003**: タスク詳細モーダルが960px幅・2カラムで開き、追加・編集・削除が成功する
- **SC-004**: モーダルのコメントがチャット形式（丸型入力）で表示・追加できる
- **SC-005**: **モバイル (390px) でステータスピルが機能し、カンバンは表示されない**
- **SC-006**: **モバイル (390px) で MobileToolbar が表示される**
- **SC-007**: **タブレット (768px) で TopBar が崩れない**
- **SC-008**: ヒントバーの表示/非表示が localStorage で永続化される
- **SC-009**: TypeScript コンパイルエラー・ESLint エラーが0件
- **SC-010**: 既存のドラッグ＆ドロップが壊れていない
- **SC-011**: TaskControlBar のカテゴリバッジを複数選択し、OR 条件（選択カテゴリのいずれかに一致）でタスクがフィルタされる ★ v3追加
- **SC-012**: TaskControlBar の担当者プルダウンでフィルタを選択し、該当担当者のタスクのみ表示される ★ v3追加
- **SC-013**: CSV出力ボタンが画面上に存在しない ★ v3追加
- **SC-014**: カンバン末尾に「ステータス列を追加」ゴーストカラムが存在しない ★ v3追加
- **SC-015**: タスクカードフッターに締め切り日時（`M/d HH:mm`）が最初に表示される ★ v3追加
