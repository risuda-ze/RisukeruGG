## 手動テストシナリオ

### PC (1440px) — カンバンボード確認

1. ブラウザ幅を 1440px に設定してタスク管理画面を開く
2. **列幅**: 全カンバン列が 304px 幅であることを確認
3. **緊急度チップ**: 期限切れタスクに赤「N日超過」、当日に「今日まで」、翌日/明後日に「soon」が表示されることを確認
4. **カテゴリチップ**: アイコン付きチップが表示されることを確認（カテゴリなしタスクはチップ非表示）
5. **列の「＋」ボタン**: クリックでそのステータスが選択済みの追加モーダルが開くことを確認
6. **ヒントバー**: 初回表示 → `×` で閉じる → リロードしても非表示 → `?` ボタンで再表示
7. **D&D**: タスクカードをドラッグして別の列に移動できることを確認

### タブレット (768px) — TopBar 確認

1. ブラウザ幅を 768px に設定
2. TopBar の subtitle テキストが縦方向にはみ出さないことを確認

### モバイル (390px) — ステータスピル & MobileToolbar

1. ブラウザ幅を 390px に設定
2. **カンバン非表示**: カンバンボードが表示されないことを確認
3. **ステータスピル**: 画面上部に横スクロールのピル一覧が表示されることを確認
4. **ピル切り替え**: ピルをタップするとそのステータスのタスクリストに切り替わることを確認
5. **フルスクリーンモーダル**: タスクカードをタップすると全画面で詳細フォームが開くことを確認
6. **MobileToolbar**: 画面下部にツールバーが表示されることを確認

### タスク詳細モーダル確認

1. タスクカードをクリック（PC）
2. **モーダル幅**: 960px であることを DevTools で確認
3. **フッター**: 左に「削除」、右に「キャンセル」「保存」があることを確認
4. **コメント入力**: 丸型一行フィールド＋上向き矢印ボタンであることを確認（textarea でないこと）
5. 「タスクを追加」ボタンから新規追加 → **削除ボタン非表示**であることを確認

## 緊急度計算ロジック仕様

`src/lib/urgency.ts` の `getUrgencyLevel(dueDate: Date | null, isDone: boolean)` の返り値:

| 条件 | 返り値 |
|-----|-------|
| `isDone === true` | `'done'` |
| `dueDate === null` | `'normal'` |
| `dueDate < 今日` | `'over'` |
| `dueDate === 今日` | `'today'` |
| `1 <= 残り日数 <= 2` | `'soon'` |
| `残り日数 >= 3` | `'normal'` |

判定順: `done > over > today > soon > normal`
