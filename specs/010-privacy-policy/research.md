# Research: プライバシーポリシー

## 法的要件調査

### Decision: 日本の個人情報保護法（2022年改正）に完全準拠
**Rationale**: 対象ユーザーが主に日本在住の配信者であり、日本国内でサービスを提供するため  
**Alternatives considered**: GDPR 対応 → スコープ外とする（日本ユーザー特化、EU展開予定なし）

## 個人情報保護法の必須要件

### 利用目的の公表（第21条）

サービス提供時に個人情報を取得する際、利用目的を「通知または公表」しなければならない。  
プライバシーポリシーページとして公表する方法が一般的かつ適法。

### 安全管理措置（第23条）

技術的・組織的な安全管理措置を講じ、その旨を公表する必要がある。  
Firebase のセキュリティ機能（Security Rules、暗号化）を具体的に言及すること。

### 第三者提供の制限（第27条）

本人の同意なく第三者に提供することを原則禁止。  
「委託」（業務委託先への提供）は第三者提供に該当しないが、別途安全管理義務あり。

### 外国にある第三者への提供（第28条）

Firebase（Google LLC・米国）と Vercel（Vercel Inc.・米国）への個人情報移転について公表が必要。  
米国は個人情報委員会の「十分性認定」を受けていないため、以下いずれかの措置が必要：
- 標準的な契約条項（SCC）：Firebase Data Processing Agreement / Vercel DPA が該当
- ユーザーへの情報提供：移転先国・適切な保護措置の状況を通知

実装上は、Firebase・Vercel との契約（DPA）に基づく委託として処理し、ポリシーで開示する。

### 保有個人データに関する事項の公表（第32条）

以下の事項を公表する義務がある：
1. 個人情報取扱事業者の氏名・名称
2. 全ての保有個人データの利用目的
3. 開示等の求めの申し出先
4. 認定個人情報保護団体の名称・苦情申出先（加入している場合）

### ユーザーの権利（第33〜38条）

- 開示請求（第33条）
- 訂正・追加・削除請求（第34条）
- 利用停止・消去請求（第35条）
- 第三者提供の停止請求（第37条）
- 開示方法の指定（電磁的記録でも可）

|-----------|--------------|--------|
| メールアドレス | Googleサインイン時 | Firebase Authentication（Google OAuth） |

- 位置情報 → 取得していない
- Google Analytics / Firebase Analytics → 未導入（確認済み）
- 電話番号 → 取得していない

## 技術的調査

### Decision: `/privacy-policy` を独立した公開ページとして実装

**Rationale**: 
- 認証なしでアクセス可能にする必要がある
- 検索エンジンにインデックスされることが望ましい
- `(auth)` グループ外の App Router ルートとして作成するのが適切

**Alternatives considered**:
- モーダル表示 → ディープリンク不可・SEO非対応のため却下
- `src/app/(auth)/privacy-policy/page.tsx` → ルートグループは認証フローと関係するため混乱を招く

### Decision: 既存の `(auth)` グループ外・`src/app/privacy-policy/page.tsx` として実装

**Rationale**: `src/app/page.tsx`（トップ）と同様に、認証グループに属さない独立ページとして配置する

### Decision: アプリ情報タブをプロフィール設定ページ（`/settings/profile`）に追加

**Rationale**: 
- チャンネル設定（`/settings`）はチームスコープの設定のため不適切
- プロフィール設定はユーザー個人スコープの設定であり、アプリ情報の掲載に適切
- 既存の Tab 型に `'app-info'` を追加するだけでよく、最小変更で実現可能

## 競合サービスの参考調査

### Twitch プライバシーポリシー（参考）
- 収集情報を「アカウント情報」「使用データ」「決済情報」などカテゴリ別に列挙
- 利用目的を明確に列挙
- 第三者パートナーを明示
- ユーザーの権利（アクセス・削除・ポータビリティ）を一覧化

### YouTube / Google のアプローチ（参考）
- 収集情報→利用目的→提供先→管理方法の順序で構成
- 外国への移転を明示
- ユーザーが取れる行動（Google アカウント管理）を明示

- にじさんじ（ANYCOLOR）：個人情報取扱方針として公開
- TwitCasting：個人情報保護方針として詳細公開

## プライバシーポリシー本文に含める主要条項（草案）

以下はポリシー文書に含める項目の構成案。Generator 実装時の参考とすること。

1. **はじめに**：リスケるGG（以下「本サービス」）の個人情報の取り扱い方針

2. **事業者情報**：〔プレースホルダー：事業者名・所在地・代表者名・問い合わせ先を記入〕

3. **取得する個人情報**：上記の特定済み情報を列挙

4. **利用目的**：
   - 本サービスの提供・維持・改善
   - ユーザー認証・本人確認
   - チーム機能・コラボ機能の提供
   - プッシュ通知・アプリ内通知の配信
   - 問い合わせへの対応
   - 不正アクセスの検知・防止

5. **第三者提供**：原則として本人の同意なく第三者提供しない。ただし法令に基づく場合を除く。

6. **委託**：Google LLC・Vercel Inc. へ業務委託（第三者提供には該当しない）

7. **外国への提供**：米国（適切な保護措置：各社 DPA）

8. **Cookie・認証トークン**：Firebase Authentication が Session Storage / Cookie を使用。ブラウザ設定で無効化可能（ただしサービスが利用不能になる）

9. **安全管理措置**：Firebase Security Rules による Firestore アクセス制御、HTTPS 通信の強制、Cloud Functions での認証チェック

10. **ユーザーの権利**：開示・訂正・削除・利用停止の請求先（お問い合わせ窓口）

11. **お問い合わせ窓口**：〔プレースホルダー〕

12. **ポリシーの変更**：本ページにて告知。重要な変更はアプリ内通知で周知

13. **制定日・改定日**：制定 2026年XX月XX日
