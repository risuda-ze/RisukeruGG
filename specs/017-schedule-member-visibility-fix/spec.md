# 仕様書: スケジュール画面のメンバー予定が表示されないバグ修正

**Branch**: `017-schedule-member-visibility-fix` | **Date**: 2026-06-27
**Status**: Draft

## 概要

スケジュール一覧画面で「メンバーの予定」ボタンをクリックしても、他のチームメンバーの予定が表示されない。ボタンの表示ラベルは「メンバー表示中」に切り替わるが、カレンダー上にメンバー予定が一切描画されない。本仕様ではこの不具合の原因を特定し、修正する。

> **バージョン方針**: 本機能は他機能との競合を避けるため、アクティブバージョンを **017** とする。`011-team-permission-member-schedule` で追加した「メンバー予定参照機能」の回帰バグ修正という位置づけ。

---

## バグ詳細

### 症状

- スケジュール画面右上の「メンバーの予定」トグルボタンをクリックすると、ラベルが「メンバー表示中」に変わる（＝UI 状態は切り替わっている）
- しかし、カレンダー（月／週ビュー）に他メンバーの予定が表示されない
- エラーメッセージも表示されない（サイレント失敗）

### 原因（特定済み）

メンバー予定の取得は `src/lib/repositories/memberCalendars.ts` の `subscribeMemberCalendarEvents` が **コレクショングループクエリ** `collectionGroup(db, 'events')` で行う。

```ts
// src/lib/repositories/memberCalendars.ts:73
query(collectionGroup(db, 'events'), where('teamId', '==', teamId))
```

一方、Firestore セキュリティルール（`firestore.rules:106-113`）は `events` サブコレクションへのアクセスを **ネストパスのみ** で許可している。

```
match /teams/{teamId}/memberCalendars/{userId}/events/{eventId} {
  allow read: if isTeamMember(teamId);
  ...
}
```

**Firestore のコレクショングループクエリは、ネストパスのルールでは認可されない。** コレクショングループに対するクエリを許可するには、再帰ワイルドカード（`match /{path=**}/events/{eventId}`）を使ったルールが必要。現状そのルールが存在しないため、クエリは `permission-denied` で拒否される。

さらに `subscribeMemberCalendarEvents` の `onSnapshot` に **エラーコールバックが無い** ため、拒否がコンソール以外に現れず、ユーザーには「ボタンを押しても何も起きない」サイレント失敗として観測される。

### 影響範囲

- スケジュール画面の「メンバーの予定」表示機能（`011` で追加）が全ユーザーで機能しない
- メンバー予定データの **書き込み**（ログイン時同期 / `saveMemberCalendarEvents`）はネストパスの write ルールで許可されているため、Firestore 上にデータは正しく保存されている。**読み取り側のみが壊れている。**

## 受け入れ基準

- [ ] **AC-1**: チームメンバー A がログイン時に Google カレンダー予定を同期した状態で、別メンバー B がスケジュール画面の「メンバーの予定」トグルを ON にすると、A の同期済み予定がカレンダーに表示される
- [ ] **AC-2**: 「メンバーの予定」トグルを OFF にすると、メンバー予定がカレンダーから消える（既存挙動を維持）
- [ ] **AC-3**: メンバー予定のイベントをクリックすると、読み取り専用ポップアップ（「メンバーの予定」ラベル付き）が表示される（既存挙動を維持）
- [ ] **AC-4**: Google カレンダー直接接続済みユーザーは、自分の同期済み予定が二重表示されない（既存の重複除外ロジックを維持）
- [ ] **AC-5**: 他チームのメンバー予定は表示されない（`teamId` フィルタが有効）
- [ ] **AC-6**: コレクショングループクエリが失敗した場合、サイレントに握り潰さずエラーがログに記録される
- [ ] **AC-7**: 既存のスケジュール表示（チーム予定・Google カレンダー個人予定）に回帰がない

## スコープ外

- 「メンバーの予定」UI のデザイン変更
- 新規メンバー予定機能の追加
